## Theme

Place a working agent in an environment where people already work, communicate, or live. The environment must contribute meaningful context, interaction, or action capabilities to the experience.

Potential environments include workplace software, messaging, browsers, mobile devices, voice interfaces, wearables, and physical spaces. These are examples rather than separate competition tracks. Eligible projects enter a shared global competition.
